• Enabled core GWT support without an Ultimate subscription in unified IntelliJ IDEA 2026.3: GWT facets/module XML, SDK management, compiler integration, Java/RPC inspections, UiBinder, ClientBundle, JSNI, component creation, and Maven/Gradle import. Applications can be run through Maven goals or Gradle tasks.
  • Made Ultimate integrations optional. These features still require an Ultimate subscription and their bundled plugins enabled:
    • Web/Servlets: web.xml inspections and servlet registration, Web facet/root integration, and WAR artifact import and validation.
    • Web/Servlets and Application Servers: dedicated GWT DevMode/Super Dev Mode run configurations, sample web-application setup, and application-server integration.
    • JavaScript Debugger, in addition to the Web/server plugins: GWT JavaScript debugging integration.
  • Preserved existing Web facet associations when editing without Web/Servlets support, and added separate automated free-mode and full-integration runtime checks.
  • Kept per-module compilation controls and GWT JUnit classpath/argument setup available in free mode; only Web output-path controls and test web.xml copying require Web/Servlets support.
  • The minimum supported IDE build remains 263; older standalone Community Edition versions are not supported.
